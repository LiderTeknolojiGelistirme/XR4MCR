# Saved Scenario Files

This folder contains **pre-prepared scenario files** (`.mcrsf` format) for the application.  
These scenarios are **examples** that demonstrate best practices in scenario design and can be directly loaded and used in the application.

## Purpose
The included scenarios are based on training examples illustrating:
- Non-linear feedback using event ports.
- Step-by-step guided assembly processes.
- Sequential task flows with clear instructions, visual cues, and audio feedback.

For more details on the design principles and implementations, please refer to the **"Best Practice in Action: Scenario Examples"** section in the documentation.

## How to Use
1. Copy the `.mcrsf` files from this folder into the following directory:

C:\Users\%USERNAME%\AppData\LocalLow\LTG\OC1_XR4MCR_FinalApplication


**Quick Access:** Press **Win + R**, paste the following, and press Enter:

%USERPROFILE%\AppData\LocalLow\LTG\OC1_XR4MCR_FinalApplication


2. Launch the application.
3. Load the scenarios from the in-app scenario selection menu.

## Notes
- These scenarios are provided for demonstration and learning purposes.
- You can modify or extend them to fit your own use cases.
